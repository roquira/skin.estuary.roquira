My personal fork of Estuary for Kodi 22, designed for [my CoreELEC build](https://github.com/roquira/CoreELEC).

It adds an Anime home category and a few minor tweaks.

## Installation

1. Download the zip from [Releases](https://github.com/roquira/skin.estuary.roquira/releases/latest).
2. In Kodi, allow unknown sources (Settings > System > Add-ons) and use Add-ons > Install from zip file.
3. Switch to Estuary (roquira) under Settings > Interface > Skin.
4. Choose your anime sources under Configure skin > Main menu items > Anime source settings.

The power menu's library items need my [CoreELEC build](https://github.com/roquira/CoreELEC); on other Kodi builds they stay hidden.
